HOW TO UPDATE THE PRODUCT DATABASE
===================================

1. Edit PRODUCT_DATA.xlsx in this folder
   - Column A: Brand Name  (exactly as it appears in the MARG PDF)
   - Column B: Generic Name
   - Column C: Manufacturer
   - Column D: HSN Code

2. Save the Excel file

3. Go back to the main app folder and double-click:
   "UPDATE PRODUCTS - Double Click Me.bat"

4. Done — the app will use the new data next time you start it.

NOTE: Brand Name must match what MARG prints in the invoice PDF.
      Leave Generic Name / Manufacturer / HSN blank if unknown — 
      the app will leave those fields empty for manual entry.
